# ATELIER 기업 분석 화면 · 가독성/개인 메모 개편

시행: 2026-11-09. 기존 52개 기업의 정적 리서치 화면을 간단히 정리합니다.

## 사용자 동선

- **기업 분석 → 기업 선택**: 기업 상단에는 산업·기업·차트(클릭 시만 외부 로드) 및 기존 지수 비교가 유지됩니다.
- **사업 이해**: 회사를 이해하는 데 필요한 분야/사업 범주만 요약. 이미 검증된 사업 설명 자료의 범위를 넘어 임의 매출·시장점유율을 작성하지 않습니다.
- **실적·이슈**: 가장 최근 검증된 SEC GAAP 분기 실적(해당되는 경우)과 소비재·국내 사업부 고유 KPI를 유지하며, 뒤에 기업별 공식 발표·원문 검토·미검증 뉴스 제목을 최대 5건 노출합니다. 근거가 없으면 비워둔 사실을 명시합니다.
- **파이프라인**: 바이오·제약 기업에만 표시. 기존 등록 임상 및 약물별 주요 완료 일정을 유지합니다.
- **나의 메모**: 초기 검증 질문을 참고로 보여주고, **투자 논리 한 줄**과 **날짜·시간이 자동 기록되는 자유 메모**를 저장할 수 있습니다. 최근 5건 우선 표시, 오래된 기록은 펼쳐보기.

## SEC 분기 표시

- 데이터의 `fiscalYear`·`fiscalPeriod`를 우선합니다. 예: FY2027 Q2 → **FY27 2Q**. 같은 2026년 3분기 달력 기간이라는 이유로 `3Q26`으로 표기하지 않습니다.
- 아래에 해당 회사 분기 종료일, SEC 제출일과 출처를 병기합니다.
- 회계연도/분기가 누락됐으면 **분기 종료일**로만 표시해 회계분기를 임의 추정하지 않습니다.
- 매출/영업이익/순이익 비교는 같은 GAAP 3개월 기준의 요요(YoY)·전분기(QoQ) 수치만 보여주며, 매출액과 운영 KPI를 합산하지 않습니다.

## 기업별 이슈 기준

- **공식/원문 검토 3건 + 제목만 수집 2건** 최대 5건.
- `atelier-weekly.json`: 티커·산업이 일치하고 `공식 …` / `편집 원문 대조`로 검증된 날짜 있는 원문.
- `weekly-content.json`: 사람이 원문 대조·편집했다고 기록된 기사/IR. 동일 원문 URL은 중복 제외.
- `weekly-research.json`: 패션 업종의 **Google News RSS 제목**만 사용, 기업 티커가 정확히 일치하는 경우에만 노출. 이를 **‘기사 제목 · 본문 미확인’**으로 표시하고 기사를 읽은 것처럼 해석하지 않음.
- Yahoo Finance 종목별 뉴스·Reuters 검색·SEC/DART 원문 링크를 별도로 제공합니다. Reuters/Yahoo 기사의 전문을 스크래핑·재게시하지 않으며, 외부 검색 링크의 기사 목록과 최신성은 각 사이트에 따릅니다.
- 기존 뉴스 RSS는 패션 중심이며 바이오·소비재·국내 기업의 새로운 외부 뉴스 검색을 자동으로 수집·분류하는 기능은 아직 없습니다. 따라서 기사 없음과 사건 없음은 다릅니다.

## 개인 메모·백업 보존

- 동일 키 `ATELIER_V23_THESIS_LOCAL_ONLY`을 계속 사용해 기존 `hypothesis`, `choice`, `riskOverride`, `note`, `at` 등의 필드를 **삭제하지 않습니다**.
- 새 `memoEntries` 배열을 추가해 `{id, at(ISO 8601), text}` 형식으로 순차 기록. 사용자가 저장할 때 로컬 시각에 맞춰 날짜가 표시되며 JSON에는 ISO 날짜로 저장됩니다.
- 기존 판단·위험·메모는 접힘형 **‘기존 투자 판단·반증 기록 보관’** 안에 읽기 전용으로 유지합니다.
- 삭제는 해당 날짜 메모 한 건만 대상으로 하며 저장 전에 확인. 기존 모든 기록을 삭제하는 버튼을 새 메모 화면에 두지 않습니다.
- 개인 기록은 현재 브라우저의 localStorage에만 남고, 서버·데이터 수집기에 전송하지 않습니다. 기존 자료실의 백업·복원으로 새로운 `memoEntries`도 함께 보존됩니다.
- 다른 기기 동기화는 지원하지 않습니다.
