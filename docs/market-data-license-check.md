# ATELIER 2-1 · 시세 공급사 공개·저장 권한 점검표

2026-11-06 기준 공식 Twelve Data 안내 확인. **계약 체결 또는 재배포 허가가 이미 존재한다는 의미가 아닙니다.**

## 공급사 가이드에서 확인된 사실
- Individual(Grow, Pro, Ultra) 요금제는 개인·내부 개발 및 비공개 용도로 제한되며, 공개 웹사이트로의 재배포 권한을 제공하지 않습니다.
- Business(Venture, Enterprise 등)도 상품 표시·파생 데이터 활용·외부 제공의 범위에 따라 조건이 다릅니다. 파생 수익률을 저장·표시하더라도 원본 가격을 복원할 수 없어야 한다는 제한이 명시되어 있습니다.
- 미국 주식 데이터의 외부 배포 및 거래소별 사용에는 US Equities/Redistribution 관련 추가 권한이 요구될 수 있습니다. 기본 요금제의 접근 가능 여부가 외부 공개 사용권을 의미하지 않습니다.
- 공개 표시에 필요한 출처 표기는 원칙적으로 **Data provided by Twelve Data**와 공식 사이트로의 표시 링크입니다. 별도의 거래소 표시 요건은 계약에 따라 추가될 수 있습니다.
- 장 마감 데이터(EOD)만 사용하며 **실시간 알림이 아님**을 명시합니다.

## 공급사에 확인할 5가지 (운영 전 필수)
1. 이 공개 GitHub Pages 웹사이트에 미국 47개 추적 기업의 일간 **배당·분할 조정 수익률**을 보여줄 수 있는 정확한 상품·계약명은?
2. 수익률 계산 결과(일간 변동률, 20일 변동 폭 대비 배수, 거래량 배수)를 **파생 데이터**로 공개할 권한이 있는가? 1일 변화율을 연속 저장하는 경우 복원 가능성 규정은 어떻게 적용되는가?
3. `price-events.json`을 공개 Git 저장소의 **과거 커밋·릴리스 파일까지 보존**해도 되는가? 필요한 데이터 만료·삭제 조건은?
4. `adjust=all` EOD 종가와 별도 일별 거래량을 표시·보관하지 않고 파생 지표만 저장할 때, 필요한 **거래소별 추가 계약과 출처 표기**는?
5. 거래소별 지연 시간, API 사용량·요청 제한, 전체 47개 종목 갱신 가능 여부, 공개 서비스 표시 요건은?

## 코드 활성화 조건

다음 값은 실제 계약·승인을 확인한 운영자만 설정합니다. **환경 변수는 계약 증거가 아니며** 승인 전에는 값을 설정하지 않습니다.

- `TWELVEDATA_API_KEY`: 유효한 공급사 키
- `MARKET_DATA_DISPLAY_OK=true` (또는 `1`): 외부 표시 사용권 확인
- `MARKET_DERIVED_PUBLIC_OK=true`: 파생 급등락 지표를 공개 사이트에 표시할 권리 확인
- `MARKET_DERIVED_GIT_STORAGE_OK=true`: 파생 지표를 공개 Git 저장소와 Pages 이전 버전에 보관할 권리 확인

시세가 연결되지 않았거나 하나라도 불충족하면, 실제 종목 급등락 수치·관련 원인 추정은 공개하지 않습니다.

## 구현된 안전장치와 남은 검증

- 한 번 받은 종가·거래량을 재사용: 주가 API를 중복 호출하지 않음. 공개 파일에는 원시 종가·일별 거래량을 저장하지 않음.
- 매일 47개를 수집하도록 워크플로 요청은 설정되어 있지만, **API의 실제 성공 수는 독립적으로 검사**하며 '시도', '검증됨', '실패', '미시도'를 분리.
- 일간 가격 등락률 8% 이상 + 이전 20거래일 평균 절대 일별 변동폭의 2배 이상만 후보. 소수점 반올림 전 수치로 판정.
- 마지막 확인 거래일이 UTC 날짜 기준 5일 넘게 경과하면 새 알림으로 간주하지 않음. EOD 거래일 기준이므로 장중/실시간 알림과 다름.
- 거래량이 현재 세션 및 직전 20세션에 모두 존재할 때만 **금일 거래량 / 20거래일 평균 거래량**을 산출. 원시 거래량의 분할 조정 여부는 공급사와 별도 확인이 필요하며 거래량만으로 매수 압력이나 원인을 확정하지 않음.
- 업종별 임계값과 검증된 오탐률 수치는 **아직 없음**. 실제 권한 있는 관찰 데이터가 누적되기 전 임의로 설정하지 않음.

## 대안

외부 데이터 공개 계약을 확보하지 못하는 경우, 기존 사이트의 공급사 위젯/공식 공시 링크만 사용하고 `price-events.json`은 차단 상태로 유지합니다. 공개할 권리가 검증되지 않은 급등락률을 웹 스크래핑하거나 무료 API로 대체하지 않습니다.

## 추가 확인 · 2026-11-09

- Twelve Data의 2026년 가이드에는 **미국 EOD 자료에 대한 기본 API 접근**과 **외부 재배포 허가**가 별개로 안내됩니다. EOD 조회 가능 ≠ 공개 GitHub Pages 게시 가능.
- 유료 비즈니스 요금제도 외부 재배포가 필요한 경우 별도 계약·애드온 권한을 확인해야 합니다. 공개 파생 변화율을 장기간 저장할 경우, 원래 가격이 복원되지 않아야 한다는 약관 및 계약의 보존기간·종료 후 삭제 요건을 검토해야 합니다.
- `scripts/audit_price_alerts.py`는 적법하게 내부 분석할 수 있는 데이터를 **개인 작업 환경에서만** 평가하는 보조 도구입니다. 이 도구의 존재가 공개 저장 권한을 제공하지 않습니다.
